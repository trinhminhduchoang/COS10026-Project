Reference: ED105

Front-end Developer

Apply for this role

What success looks like

Learners can use the features you build across different devices and assistive technologies, while educators can focus on teaching instead of troubleshooting.

Build responsive, accessible interfaces for online learning products used by educators and learners in a Vietnamese education context.

Salary
VND 300,000,000–480,000,000 per year + benefits
Reports to
Engineering Lead
Location
Ho Chi Minh City · hybrid

Key responsibilities

  1. Develop and maintain responsive interfaces using HTML, CSS and JavaScript.
  2. Work with designers and educators to turn learning needs into clear user experiences.
  3. Review code, test accessibility and improve performance across supported browsers.

Essential requirements

  • Experience building web interfaces with semantic HTML and modern CSS.
  • Working knowledge of JavaScript and accessible interaction patterns.
  • Strong communication and a collaborative approach to problem-solving.

Preferable requirements

  • Experience with a component-based framework such as React or Vue.
  • Familiarity with WCAG accessibility guidance and automated testing.
  • Interest in education, learning platforms or digital inclusion.
